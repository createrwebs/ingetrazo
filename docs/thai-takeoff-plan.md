## ราคา + BOQ (เฟส D/E)

- ฐานราคาในตัว: บัญชีราคากลางกรมโยธาฯ 2568 + ราคาปลีกเฉลี่ย (แก้ได้, แสดงแหล่งที่มา)
- ค่าแรง 2568 (ตรวจแล้ว): ก่ออิฐแดงครึ่งแผ่น 94 บ./ตร.ม., บล็อก 7 ซม. 84,
  มวลเบา 56, ฉาบเรียบ 63, เสาเอ็น/ทับหลัง 44 บ./ม. (OneStockHome อ้างกรมโยธาฯ)
- API: `GET https://dataapi.moc.go.th/csi-indexes?province_code=&com_code=&from_year=&to_year=`
  → ราคาเฉลี่ยรายจังหวัด รายเดือน (ชื่อสินค้าไทย+หน่วย) — **ทดสอบจาก sandbox แล้ว timeout**
  → ต้องทดสอบบนเครื่องจริงตอน implement; แหล่งสำรอง: TPSO backend, mirror JSON
  (`$INGETRAZO_PRICES` override แบบ library.py), endpoint ผู้ใช้เอง
- ลำดับชั้น: แก้เองรายโครงการ > CSV ใบเสนอราคา > cache ออนไลน์ > ฐานในตัว (offline ใช้ได้เสมอ)
- BOQ = ค่าวัสดุ + ค่าแรง + โสหุ้ย% + กำไร% + VAT 7% (สวิตช์ปิดไว้ default)
- ร้านค้าปลีก (Thai Watsadu/HomePro/Global House) ไม่มี public API → ไม่ scrape;
  ออกแบบ PriceProvider ให้เสียบเพิ่มได้

## เฟส G — หน้างาน + นำเสนอ (เสร็จแล้ว)

- **จัดกลุ่มตามชั้น/โซน:** แถบผลถอดแบบสลับ "หมวดงาน ↔ ชั้น/โซน" — โซน = ชื่อ group ชั้นบนสุด
  (หรือ layer) ของวัตถุ, geometry อิสระ = "(ทั่วไป)" — วิศวกรแยกยอดตามงวดเท/ชั้นได้
- **FF&E (เฟอร์นิเจอร์และสุขภัณฑ์):** นับ component ที่ตั้งชื่อตามจำนวนตัว — แสดงในตารางประกอบ + ชีท Excel
- **Export Excel (.xls SpreadsheetML 2003):** ไฟล์เดียวหลายชีท (วัสดุ/ใบสั่งซื้อ/BOQ/ห้อง/สี/ประตู-หน้าต่าง/เหล็ก/FF&E)
  XML ล้วนไม่เพิ่ม dependency, ตัวเลขเป็น Number ให้ Excel รวมยอดได้, ไทยครบ
- **PDF งานผิว (finishes):** รายงาน A4 ห้อง+วัสดุผิว/สี/ประตู-หน้าต่าง/เหล็ก/FF&E สำหรับนำเสนอ
- **งานดิน (ปิดไว้ default):** ขุดดิน = พื้นที่ฐานราก × (ลึกใต้ดิน + เผื่อ 0.30 ม.) × ดินฟู 1.25,
  ถมกลับ = ขุด − คอนกรีตฐานราก — เปิดได้ในตั้งค่า, ป้าย "ประมาณ"
- **ลายปูกระเบื้อง:** ตรง (เผื่อ 10%) / เฉียง (เผื่อ 15%) — ตั้งค่าในหมวดผิวพื้น

## เฟส F — ฟีเจอร์รายบทบาท (เสร็จแล้ว)

- **ตารางประกอบ (Schedules tab):** ห้อง (IfcSpace: พื้น/สูง/เส้นรอบ/ผนัง/ฝ้า + วัสดุผิวรายห้อง),
  สีแยกตามวัสดุจริง (registry name/texture/สี), ตารางประตู-หน้าต่าง (แบบ×ขนาด×จำนวน),
  เหล็กเสริมแยกตามขนาด Ø (น้ำหนักแม่น + จำนวนเส้น 10 ม.), Preflight ตรวจแบบ
- **งานผิวรายห้อง:** ตั้งค่า พื้น/ผนัง/ฝ้า/บัว ได้ (กระเบื้อง/สี/วอลล์เปเปอร์) — บันทึกไปกับเอกสาร
- **ผู้ช่วยเสนอ tag (Suggest BIM tags… ในแผง BIM):** เสนอคลาส IFC จากรูปทรง
  (ผนัง/พื้น/เสา/คาน/ฐานราก/หลังคา/ประตู/หน้าต่าง) — ผู้ใช้ติ๊กยืนยันเอง ไม่ติดอัตโนมัติ
- **เทียบแบบ (Compare tab):** บันทึก snapshot ก่อนแก้แบบ → เทียบหลังแก้ → ส่วนต่างปริมาณ
  (change order) เก็บ 10 อันล่าสุดไปกับเอกสาร
- **AI recipe:** เพิ่มคำสั่ง tag BIM + ถอดวัสดุ + ตารางห้อง + เสนอ tag ใน core/ai_recipes.py
- หมายเหตุ: ตารางรายห้องเป็นมุมมองแยก ไม่บวกเข้าถอดแบบหลัก (กันนับซ้ำสี/กระเบื้อง)

## วิธีใช้งาน (เฟส A–E)

1. เปิดโปรแกรม — เป็นไทยทันที (ครั้งแรก)
2. ออกแบบบ้าน → เลือกผนัง/พื้น/เสา → แผง BIM (Window ▸ Panels) → ติด tag
   (หรือติ๊ก "ติดแท็กขณะวาด" แล้ววาดใหม่)
3. กด **ถอดแบบก่อสร้าง…** (แผง BIM หรือเมนู Tools หรือค้น F3)
4. แท็บ "วัสดุแยกหมวดงาน" / "ใบสั่งซื้อ" / "อัตราส่วนและตัวเลือก" (preset ไทย 3 แบบ)
5. ส่งออก CSV (Excel ไทยไม่เพี้ยน) / PDF A4 / คัดลอกตาราง
6. ราคา: แท็บ "ราคา / BOQ" → เปิดสวิตช์ → เลือกจังหวัด → "ซิงก์ราคาออนไลน์"
   (กระทรวงพาณิชย์) หรือนำเข้า CSV ร้าน / แก้ราคาในตารางเอง → โสหุ้ย/กำไร/VAT
